## 2. 吸色

| 操作 | 说明 |
| --- | --- |
| 点「开始吸色」 | 进入吸色模式，鼠标旁出现放大镜 |
| `Ctrl+Shift+X` | 全局热键，任意时刻开始吸色（可改） |
| 移动鼠标 | 放大镜实时跟随，中心十字即取样点 |
| **左键单击** | 确认取色 |
| 右键 / `Esc` | 取消 |
| 输入框粘贴 `#RRGGBB` 或 `r,g,b` + 回车 | 手动导入颜色 |

放大镜设置（设置页）：

- **放大镜倍率** 2×–40×，默认 12×
- **取样区域** 3–41 px，默认 15 px（放大镜一次抓多大的区域）
- **中心平均** 1 / 3 / 5 —— 对有噪点的截图或抗锯齿边缘，取中心 3×3、5×5 的平均值更稳
- **放大镜跟随光标** 关闭后放大镜固定不动，适合精细比对

> 在 125% / 150% 缩放的屏幕上，应用会声明 Per-Monitor DPI 感知，
> 取到的就是物理像素，不会整体偏移。

## 3. 读数值

左侧「色彩数值」给出四组值，每项右侧都有「复制」按钮：

- **HEX** `#RRGGBB`
- **RGB** `0-255, 0-255, 0-255`
- **HSV** 色相° / 饱和度% / 明度%
- **LAB** CIE L\*a\*b\*（D65）

下方一行显示「最接近：品牌 色号 名称 · ΔE x.xx（判定）」。

## 4. 配色建议

每条建议包含：

1. **ΔE 徽章**：越小越接近；颜色对应可辨分级
2. **主色号**：品牌 + 色号 + 中英文名 + 光泽 + 漆基
3. **使用方式**：`可直接瓶用` 或 `需调配`
4. **色卡对比条**：目标色 → 混合结果 → 各组分
5. **比例堆叠条**：段内标注色号 + 百分比 + 滴数；底部给出 `滴数比 = 百分比`
6. **预估用量**：纯漆 / 稀释剂 / 混合液 / 约几瓶
7. **替代色号**：同标准色号优先，其次跨品牌最近色，每条带理由
8. **提示**：遮盖力、跨品牌相容性、稀释度等注意事项

顶部工具条可切换**建议范围**（全部品牌 / 单个品牌 / 日系 / 欧系）与**色差公式**。

### ΔE 怎么看

| ΔE2000 | 判定 | 该怎么办 |
| --- | --- | --- |
| < 1.0 | 数字色卡非常接近 | 优先少量试喷确认 |
| 1.0 – 2.0 | 数字色卡接近 | 优先少量试喷确认 |
| 2.0 – 3.5 | 可见但可接受 | 视作品要求决定 |
| 3.5 – 5.0 | 明显不同 | 建议按配方调配 |
| > 5.0 | 完全不同的颜色 | 必须调配或换色号 |

## 5. 用量参数

| 参数 | 建议 |
| --- | --- |
| 喷涂面积 | 1/35 战车约 500 cm²；1/100 飞机约 300 cm²；1/8 胸像约 150 cm² |
| 喷涂层数 | 通常 2 层；黄 / 橙 / 荧光自动 +1 |
| 稀释比例 | 水性丙烯酸喷笔 1:1 ~ 1:2；硝基 1:1.5 ~ 1:2；**预稀释漆填 0** |
| 施工方式 | 喷笔 / 笔涂 / 喷罐（损耗系数不同） |
| 基材状态 | 已上补土 / **3D 打印件未处理** / 光面塑料 |
| 原漆单位用量 | 默认 55 ml/m²/层，仅为旧参数迁移值，需按自己的喷笔校准 |
| 余量系数 | 默认 1.15，计入调漆杯残留与试喷 |
| 固定试喷/残留损耗 | 默认0 ml原漆；每次调漆另加一次，不乘面积或层数，避免与比例余量重复计入 |
| 预稀释自动模式 | 默认开启；Model Air、SMS在喷笔模式下额外稀释剂按0估算，需手动加稀释剂时关闭 |

用量现在先计算原漆需求，再按比例添加稀释剂。增加稀释剂不会让同一面积的原漆需求下降。
建议卡片与用量页共用同一份已按遮盖力和产品属性调整的估算。

默认配方只使用同一产品线的色号。需要跨线混配时，可在设置中主动勾选“允许跨产品线混配（兼容性未验证）”。
百分比、颜色预览、ΔE和各组分毫升量都以最终整数滴数为准；屏幕色差是预测值，不能视为实喷测量。

## 6. 校准

试喷后发现某个色号的数字色值和实际不符：

1. 在对应建议卡片点「校准色值」
2. 输入你实测的 `#RRGGBB`
3. 立即生效（写入 `%APPDATA%\ModelPaintPal\paint_overrides.json` 或便携版 `userdata\`）
4. 设置页可查看全部校准项，一键清除

校准**不会**修改随包数据，重装 / 升级不受影响。

## 7. 历史与收藏

- **历史记录**：每次取色自动写入（同色去重并置顶），默认保留 200 条
- **收藏夹**：点左侧「收藏此色」或历史条目上的 ★
- 点任意色块 → 重新载入该颜色；点 ✕ → 删除

## 8. 导出与分享

| 入口 | 产出 | 适用场景 |
| --- | --- | --- |
| 卡片「复制配方」 | 纯文本 | 随手贴到聊天里 |
| 卡片「复制 Markdown」 | Markdown 表格 | 写笔记 / 写文档 |
| 菜单「文件 → 导出建议为 JSON…」 | `.json` | 备份、二次处理、喂给脚本 |
| 菜单「文件 → 导出建议为 Markdown…」 | `.md` | 完整报告存档 |
| 菜单「文件 → 导出建议为 CSV…」 | `.csv` | 丢进 Excel 做记录 / 比价 |
| 菜单「文件 → 复制分享文本」 | 纯文本配色卡 | 发群、发论坛求建议（不带表格，不会错行） |

「复制分享文本」的快捷键是 `Ctrl+Alt+C`（避免与全局「复制色值」的 `Ctrl+Shift+C` 冲突），
内容包含目标色、前两套方案的滴数与百分比、混合后色值、预估用量与替代色号。

## 9. 3D 打印件涂装建议（结合本工具）

1. **打磨**：PLA 用 320 → 1000 目水砂纸逐级打磨；树脂件清洗后二次固化
2. **水补土**：喷一层郡士 Mr. Surfacer 1000/1200，稀释约 1:2，干后 1000 目轻磨
   —— 这一步能把「基材状态」从 `raw_print`（1.30×）降到 `primed`（1.00×），省漆又显色准
3. **底漆**：薄喷多层，每层间隔 10–15 分钟
4. **面漆**：喷笔 0.3 mm 口径、18–22 PSI、距离 8–15 cm、稀释 1:1~1:2
5. **保护漆**：先确认最终光泽 —— 消光会变浅、光泽会更深，
   评估颜色时请在最终光泽状态下判断

> 用本工具吸色时，**尽量在最终要呈现的光泽状态下取样**，或先喷一小块样板再吸。

## 10. 快捷键

| 快捷键 | 功能 | 可否修改 |
| --- | --- | --- |
| `Ctrl+Shift+X` | 开始吸色 | ✅ 设置页 |
| `Ctrl+Shift+C` | 复制当前 HEX | ✅ 设置页 |
| `Ctrl+Alt+C` | 复制分享文本 | ❌（固定，避开全局热键） |
| `Esc` / 右键 | 取消吸色 | ❌ |
| 左键 | 确认取色 | ❌ |

热键通过 Windows `RegisterHotKey` 注册，不需要管理员权限。
若与其它软件冲突，注册会失败并在状态栏提示 —— 换一个组合即可。
